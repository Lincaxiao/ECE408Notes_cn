独立外部核验
核验日期：2026-10-17。以下仅核验 CUDA 接口和执行模型边界，未扩展成额外课程要求。

NVIDIA CUDA Programming Guide, C/C++ Language Extensions, Legacy Atomic Functions / atomicCAS
https://docs.nvidia.com/cuda/cuda-programming-guide/05-appendices/cpp-language-extensions.html#legacy-atomic-functions
https://docs.nvidia.com/cuda/cuda-programming-guide/05-appendices/cpp-language-extensions.html#atomiccas
核验：atomicAdd 和 atomicCAS 返回旧值；CAS 的比较替换语义；无后缀传统原子接口为设备作用域、宽松内存顺序。

NVIDIA CUDA Programming Guide, CUDA C++ Memory Model, Data Races
https://docs.nvidia.com/cuda/cuda-programming-guide/05-appendices/cuda-cpp-memory-model.html#data-races
核验：冲突原子访问的作用域条件；普通访问与并发原子写不自动形成安全同步。
代码以同值 CAS 取得初始观测值，是据此采用的纯原子读写实现选择。

NVIDIA CUDA Programming Guide, Advanced Kernel Programming, Independent Thread Scheduling
https://docs.nvidia.com/cuda/cuda-programming-guide/03-advanced/advanced-kernel-programming.html#independent-thread-scheduling
NVIDIA CUDA C++ Programming Guide 12.6.3, SIMT Architecture
https://docs.nvidia.com/cuda/archive/12.6.3/cuda-c-programming-guide/index.html#simt-architecture
核验：传统线程束共享程序计数器模型的自旋锁进度问题，以及独立线程调度改变的执行前提。

代码文件
code/histogram.cu 由正文四个完整代码块原样提取，增加 cuda_runtime.h 与 cstddef 头文件。
它是可供 CUDA 工程包含或用 nvcc -std=c++17 -c histogram.cu 编译的实现单元，不含 main 函数。
本文档的数值与索引已作独立核对；未在 GPU 上运行代码或提供实测性能结果。

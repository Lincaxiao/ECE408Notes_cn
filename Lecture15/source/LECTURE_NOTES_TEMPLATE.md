# ECE408 中文讲义复用模板

## 1. 替换字段

- `{N}`：讲次，如 `3`
- `{NN}`：两位讲次，如 `03`
- `{EN_TITLE}`：课件英文原题
- `{SLUG}`：英文题目的下划线文件名
- `{SOURCE_PDF}`：原始课件 PDF 文件名

## 2. 成品定位

- 成品是中文讲义，正文直接定义概念、解释机制、推导公式并建立知识关系。
- 采用教材式叙述，避免“课程首先介绍……”“老师随后解释……”“课件第 x 页指出……”等教学过程转述。
- 示例：将“课程首先把线程描述为一条顺序计算”写成“线程是一条正在执行的顺序计算”。
- 假定读者不会查看原始课件，正文应独立给出理解所需的定义、条件、机制、推导和例题，不以引用原课件代替解释。
- 正文、标题下方、表格标题、代码说明和图片图注均不标注课件页码或出处；图注只解释图片内容。
- 各讲与总书均不设置“源材料差异与使用说明”、资料范围、整理说明等章节。

## 3. 文件结构

```text
Lecture/
├── ECE408.tex                       # ctexbook 总书入口
├── ECE408.pdf
├── lectures.tex                     # 讲次、英文标题、关键词清单
├── style/ece408-common.tex           # 单讲与总书共用样式
├── latexmkrc
├── TexOutput/                       # 总书辅助文件
└── Lecture{N}/
    ├── ECE408_L{NN}_{SLUG}_CN.tex    # ctexart 单讲入口
    ├── ECE408_L{NN}_{SLUG}_CN.pdf
    ├── content.tex                 # 按顺序 input 各正文小节
    ├── {SOURCE_PDF}
    ├── assets/
    ├── sections/
    │   ├── 01_orientation.tex
    │   ├── 02_<topic>.tex
    │   ├── ...
    │   └── <last>_synthesis.tex
    └── TexOutput/                  # 单讲辅助文件
```

- 保留原始课件 PDF。
- 图片统一放入 `assets/`；正文按技术逻辑拆入带两位序号的 `sections/*.tex`。
- 主文件只加载共用样式和元数据，调用 `\StandaloneLecture{N}`；正文的唯一顺序清单为各讲 `content.tex`，单讲和总书均读取该清单，不复制正文。
- 正文顶层使用 `\section`，其下使用 `\subsection` 和 `\subsubsection`；正文不写 `\chapter`。总书自动将每讲包在一个 `\chapter` 内，并为小节、图、表、公式和代码添加讲次编号。
- 标签统一添加讲次前缀，如 `\label{l6:eq:matmul}`、`\eqref{l6:eq:matmul}`、`label={l6:lst:rect}`，避免跨讲重名。
- PDF 与主 `.tex` 同级，辅助文件只进入 `TexOutput/`。

## 4. 版式与元数据

- 单讲使用 `ctexart`，总书使用 `ctexbook`；均从 `style/ece408-common.tex` 加载 letterpaper、现有页边距、标题层级、UIUC 配色、信息框和页眉页脚，避免在每讲复制导言区。
- 三级标题（`\subsubsection`，如 2.1.1）统一使用黑色加粗；不使用绿色区分该标题层级。
- 沿用已验证字体：STIX Two Text、STIX Two Math、Noto Sans Mono、Fandol；不添加系统专属字体路径。
- 单讲封面顶部仅保留 `ECE 408`，下方显示 `第{N}讲` 和课件英文原题 `{EN_TITLE}`；不显示其他课程编号或 `Applied Parallel Programming`。
- 总书封面仅以一处大号 `ECE 408` 为标题，置于蓝色标题区；调用 `\NotesCover{}{}`，不添加重复课程名、其他课程编号或副标题。
- 页眉使用课程编号与 `Lecture {N}: {EN_TITLE}`；页脚使用英文课程名和中文页码。
- PDF 元数据填写英文标题、主题和关键词；不填写 `pdfauthor`，不出现 OpenAI 或整理者信息。
- 新增宏包、TikZ library 或 `listings` 配置时修改共用样式，并回归验证总书和单讲。

## 5. 内容与语言

- 中文正文简洁、准确，以定义、因果关系、机制、公式和例题为主。
- 重要术语首次出现时写作“中文 (English)”，之后使用稳定的中文名或已定义缩写。
- 标题使用中性知识名称，如“核心内容”“关键结论”“关键公式”“例题与完整推导”。
- 删除“本稿”“本文”“整理过程”“阅读方式”“内容主线”“最后应牢牢记住”等作者自述或主观指令。
- 只有源材料明确列出时才能写学习目标；不得补写“完成本讲后，应能够……”之类推断目标。
- 不把一般技术解释写成课程规定；课程规则、评分、平台和作业要求必须有源材料依据。
- 保留必要的定义、公式、代码、表格、例题和课件截图，不以精简为由删减技术链条。

## 6. 来源边界

- 英文标题、显式学习目标、课程规则和数值优先采用课件原文。
- 课堂记录可用于补充课件省略的解释；若资料冲突，保留必要的技术条件和适用范围，不在成品中单列来源差异或整理过程。
- 不用外部资料擅自修正源材料；必要的外部核验必须单独标注。
- 图片图注直接描述图中内容，不添加课件引用。原始课件与图片来源记录作为独立文件保留，不编入讲义。
- 对推导或形式化补充说明其用途，避免把讲义解释误写成额外课程要求。

## 7. 公式、图片与代码

- 先定义符号，再推导公式；全文保持符号含义一致。
- 图片不得使用占位框；图注采用知识描述，不写“课件展示了……”。
- 代码应保持可编译语义，并使用与 L1 一致的 CUDA 代码框样式。
- 多行 C/C++ `#define` 的每个续行物理行末尾保留 `\`，最后一行不写；`\` 后不得添加注释。
- 不用大量空格对齐续行符，避免 `listings` 将 `\` 折成孤立视觉行。
- 代码标题与整个代码框应尽量作为不可分页的整体留在同一页；代码块本身超过单页可用高度时，才按程序语义拆成多个完整片段。
- 检查代码行宽、自动换行、缩进和分页，确保没有裁切、越界或无意义的跨页断裂。

## 8. 编译与扩展

从 `Lecture` 根目录编译总书：

```sh
latexmk ECE408.tex
```

单讲仍使用原入口，例如：

```sh
latexmk Lecture6/ECE408_L06_Data_Locality_and_Tiled_Matrix_Multiply_CN.tex
```

- 保持根目录 `latexmkrc` 不变，不添加局部配置。总书只生成一份封面和总目录，正文连续分页，每讲另起一页；PDF 书签保留更细的标题层级。
- 新增讲义时，在 `lectures.tex` 顺序追加 `\DeclareLecture{N}{EN_TITLE}{keywords}`，建立该讲的 `content.tex`、`sections/` 与 `assets/`，并复制以下单讲入口；总书会自动纳入清单中的全部讲次。

```tex
\documentclass[UTF8,fontset=none,zihao=-4]{ctexart}
\input{../style/ece408-common.tex}
\input{../lectures.tex}
\begin{document}
\StandaloneLecture{N}
\end{document}
```

- 图片在正文中使用 `assets/` 内的相对文件名；入口负责图片路径与嵌套输入路径。
- L1--3 的 `\code` 参数保留 LaTeX 转义规则；L4 起使用原样代码字符，新讲沿用后者。不要混用两种行内代码约定。
- 验收包含：单讲与总书全量编译、无缺图或未解析引用、无重复标签、无内容越界；检查书签和章节编号，渲染巡检全部页面缩略图，并放大检查长代码、表格、目录与章首页。
